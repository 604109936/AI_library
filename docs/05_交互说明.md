## 一、通用约定（适用于所有页面）

### 1.1 角色与登录态
| 角色 | 能力 |
| --- | --- |
| 游客（未登录） | 浏览全部模块、看视频 / 听音频 / 读全文、用智学问答、搜索、看（本地）对话历史 |
| 登录用户 | 额外：收藏、划线 / 笔记、写书评、书评点赞、阅读进度 / 历史、个人页与「我的」各列表 |

**登录拦截两种机制**：
1. **`requireLogin(action)`（按操作触发）**：游客点需登录的操作时弹出底部登录抽屉，操作挂为 `pending`，**登录成功后自动执行原操作**，不离开当前页。用于：详情/乱翻收藏、书评点赞、划线/保存笔记、写书评/发布、`/me` 个人项点击。
2. **`<RequireAuth>`（整页守卫）**：`/me/favorites`、`/me/history`、`/me/notes`、`/me/reviews`、`/me/settings`、`/me/settings/profile` 的**内容区**未登录显示「登录后查看」引导（顶栏 Header 仍渲染）。

### 1.2 全局组件
- **底部导航 `BottomNav`**：4 Tab（智学 / 泡馆 / 乱翻 / 我的），仅 4 个根页面挂载，激活青瓷绿 + spring 指示条（指示条 `layoutId=tab-indicator-${variant}`，分 light/dark）；乱翻用 dark 半透明态。二级页一律不渲染。
- **二级页顶栏 `Header`**：左返回箭头（`router.back()`，aria「返回」）+ 居中 serif 标题（可随滚动淡入）+ 右侧操作槽。
- **登录抽屉 `LoginSheet`**：全局常驻，由 store `loginOpen` 控制（见【05】）。
- **整页守卫 `RequireAuth`**：未 hydrated 显「加载中…」；未登录显「登录后查看 / 登录即可同步你的收藏、笔记与书评 /（按钮）登录 / 注册」。
- **Toast `Toaster`**：顶部居中，2.8s 自动消失；success=青瓷勾 / error=胭脂叉 / info=黄铜 i。

### 1.3 反馈与状态（统一组件，`components/ui/States.tsx`）
| 状态 | 表现 |
| --- | --- |
| 加载-列表/首屏 | `Skeleton` shimmer（各页定制结构） |
| 空状态 | `EmptyState`：图标圆/插画 + 标题 + 副标题 +（可选）行动按钮；文案各页传入 |
| 错误兜底 | `ErrorState`：默认「网络开小差了 / 请检查网络后重试 /（按钮）重试」；可传自定义标题 |
| 路由错误 | `app/error.tsx`（段级）/`app/global-error.tsx`（根级）/`app/not-found.tsx`（404） |

### 1.4 路由表（App Router）
| 路由 | 页面 | 底栏 | 登录 |
| --- | --- | --- | --- |
| `/` | 开屏页（splash，延时跳转 `/library`） | — | 否 |
| `/library` | 泡馆首页 | 显示 | 否 |
| `/library/category/[id]` | 分类列表 | 隐藏 | 状态筛选需登录 |
| `/library/book/[id]` | 书籍详情 | 隐藏 | 收藏/写书评需登录 |
| `/library/book/[id]/read` | 章节阅读 | 隐藏 | 划线/笔记需登录 |
| `/library/book/[id]/review/new` | 写书评 | 隐藏 | 发布需登录 || `/chat` | 智学（欢迎/对话） | 显示 | 否 |
| `/chat/history` | 对话历史 | 隐藏 | 否 |
| `/flip` | 乱翻 | 显示（沉浸） | 收藏需登录 |
| `/search` | 全局搜索 | 隐藏 | 否 |
| `/me` | 我的主页 | 显示 | 个人项点击需登录 |

> **开屏页 `/`（`app/page.tsx` SplashPage）**：不是重定向，而是客户端开屏页。背景 `/splash.webp`（缺图回退青瓷渐变）、馆徽 `/emblem.webp`、标题「AI 图书馆」、标语「一座懂你的智慧图书馆 / 汇尽古今好书，伴你在阅读中遇见自己」、右上「跳过 {n}s」按钮（带倒计时）、底部加载进度条；进入即预取首页（`['home']`）数据做加载缓冲，停留 3000ms（`SPLASH_MS`）后 `router.replace("/library")`，点「跳过」立即进入。

### 1.5 数据约定（纯前端 Mock）
- 无 `/api` 路由：页面直接 `await` 调用 `lib/api.ts` 的 Mock 函数（内部 `sleep` 模拟延迟），数据来自 `lib/mock/data.ts`。
- 用户数据全部存浏览器 localStorage（zustand persist：`ail-auth` / `ail-ui` / `ail-library` / `ail-reader` / `ail-chat`）。
- 列表分页 `PAGE=6`；**分类列表为真实分页 `slice(cursor, cursor+PAGE)`，不复制扩充**（注释明确「避免同一本书重复出现」）。`__` 后缀去重逻辑见于**乱翻 `getFlip`**（视频流副本 id 加 `__f…` 后缀，跳转/收藏用 `id.split("__")[0]` 还原真实 id）。

## 二、模块 0｜全局

### 【05】登录注册抽屉 · `LoginSheet`（原型 05_login_register）
- **形态**：全局常驻，从底部升起的 Modal 抽屉（圆角 24，spring 320/32），半透明遮罩（点遮罩或「先逛逛」关闭）。**非独立路由**。
- **入口**：任意 `requireLogin` 触发；`/me` 游客点头像/数据卡；`RequireAuth` 引导块的「登录 / 注册」。
- **布局**：把手 → BookHeart 青瓷图标 → 标题「登录 / 注册」（注册态「注册新账号」）→ 「体验账号 123456 / 123456（点此一键填入）」→ 邮箱/账号输入框（占位「邮箱 / 账号」）→ 密码框（占位「密码」，眼睛切明文）→（注册态）确认密码 → 主按钮（登录态显「登录」/ 注册态显「注册」/ 提交中显「请稍候…」）→ 文字链「没有账号？立即注册」/「已有账号？返回登录」→ 黄铜渐隐分隔线 →「先逛逛」。（注：「登录 / 注册」是抽屉标题，非按钮文案。）

| 元素 | 手势 | 结果 |
| --- | --- | --- |
| 体验账号按钮 | 点击 | 切登录态并一键填入 123456 / 123456 |
| 邮箱/账号框 | 输入 | 校验 `length ≥ 3` |
| 密码框 | 输入 | 校验 `length ≥ 6`；眼睛切换明文 |
| 主按钮 | 点击 | 满足校验才可点；mock 延迟 700ms → `login(email)` → toast「欢迎回来」/「注册成功，已自动登录」→ 关抽屉 → 执行 pending 操作 |
| 立即注册/返回登录 | 点击 | 抽屉内切换登录/注册态（注册多「确认密码」，要求两次一致） |
| 先逛逛 / 遮罩 | 点击 | 关抽屉，放弃操作 |

- **说明**：Mock 下任意合法输入即成功；`login` 写 `useAuth` 并 `seed()` 演示「我的」数据。**无**第三方/验证码/找回密码。

### 【06】全局搜索 · `/search`（原型 06_search）
- **形态**：二级页（无底栏）。顶栏[返回 · 圆角搜索框 · 取消]。
- **布局**：未输入=「最近搜过」（仅 hydrated 且有历史）+「热门搜索」；输入后=**仅「书籍」一组结果**。

| 元素 | 手势 | 结果 |
| --- | --- | --- |
| 搜索框 | autoFocus / 输入 | 300ms 防抖后 `search(q)`；回车立即搜（跳过防抖） |
| 清除（X，aria「清除」） | 点击 | 清空输入 |
| 最近搜过 chip | 点击 | 填入并搜 |
| 最近搜过 chip 的 ×（aria「移除」） | 点击 | 删除该条历史 |
| 「清空」 | 点击 | 清空全部最近搜过 |
| 热门搜索 chip | 点击 | 填入并搜 |
| 书籍结果（BookRow） | 点击 | 跳 `/library/book/[id]` |
| 取消 / 返回 | 点击 | `goBack()`：有历史则返回，否则去 `/library` |

- **匹配规则**：`search(q)` 返回 `{ books }`，**只按 书名/作者/标签 includes，仅书籍一组，无章节组**。**仅有结果时**才写入「最近搜过」（`addRecent`，**最多保留 5 条**）。
- **热门搜索（12 词）**：人间词话 / 活着 / 人类简史 / 认知觉醒 / 终身成长 / 被讨厌的勇气 / 刻意练习 / 心流 / 原则 / 深度工作 / 围城 / 万历十五年。
- **状态**：占位「搜索书名 / 作者 / 标签」；加载=3 骨架；出错=`ErrorState`（默认文案，Mock 下基本不触发）；有查询无结果=`EmptyState`「没有找到相关书籍 / 换个书名 / 作者 / 标签试试」。

### 【26】错误与 404
- **段级错误 `app/error.tsx`**：WifiOff 图标 +「出了点小状况」+「刷新或稍后再试，多数情况下重试即可恢复」+ 按钮「重试」（`reset()`）/「回到泡馆」（→`/library`）。
- **根级错误 `app/global-error.tsx`**：内联样式（不依赖全局 CSS）+「出了点小状况」+「请刷新页面，或稍后再试」+「重试」。
- **404 `app/not-found.tsx`**：BookX 图标 +「书架上没有这一页」+「你要找的内容可能已被移走，或链接有误」+「回到泡馆」（→`/library`）。

### 【27】深色模式
- `Providers` 内 `ThemeApplier` 读 `useUI.theme`，按 `theme === "dark"` 切 `html.dark`；在 `/me/settings` 手动切「浅色 / 深色」。**主题仅「浅色 / 深色」两态，无「跟随系统」。** 深色用 `dark-bg/dark-card/dark-text`，青瓷+黄铜+胭脂强调不变。

## 三、模块 1｜智学

### 【07/02】智学 · `/chat`（原型 07_chat_welcome / 02_chat）
- **形态**：智学 Tab 根页面（**显示底栏**，智学激活）；`Suspense` 包裹（fallback「加载中…」）。
- **顶栏**：左 History 图标（→`/chat/history`）· 中标题「智学」· 右「+」（`newSession`，busy 时禁用）。
- **空状态（无消息）**：bamboo 纹样 + Mascot(88) +「你的 AI 读书伙伴」+「通览馆藏，为你荐书 · 答疑 · 解读原文」+ 4 个示例问题按钮（前置 Sparkles）：
  - 推荐一本关于成长型思维的书 / 《终身成长》第一章讲了什么 / **图书馆里有哪些心学的书** / 帮我总结《人间词话》
- **对话态**：`ChatMessage` 列表 + 底部输入区（fixed 于底栏上方）。
- **定位还原**：`?s=会话id` 从历史还原会话；并支持 `?q=`（搜索词）与 `?mid=`（消息 id）做定位 ——`mid` 命中则精确滚到该消息并高亮 2.2s；仅 `q` 时从后往前找首条命中消息并高亮；都无则滚到底（与 `/chat/history` 搜索态 `openHit` 传参对应）。

| 元素 | 手势 | 结果 |
| --- | --- | --- |
| 示例问题 | 点击 | 直接 `send` 该问句，进对话态 |
| 输入框 | 输入 | 多行自适应；上限 500 字；Enter 发送 / Shift+Enter 换行；占位「想读点什么？问问小涤呗」 |
| 发送键 | 点击/Enter | 空内容或 busy 时禁用；推用户气泡 + AI 占位气泡，**先 600ms「思考中」态**（见【28】），随后 setInterval 16ms/2 字**假流式**逐字渲染 + 闪烁光标 |
| 「停止生成」 | 点击（生成中） | 停止思考/打字机，回写已算好的引用/推荐，保持完整 |
| 「+」新建 | 点击 | busy 时禁用；清空消息、重置会话 id |

- **AI 回答来源**：本地 `buildChatReply(q)` —— 按「书名 > 分类名 > 标签/简介 > 随机」命中一本馆藏书，拼固定模板文本；命中荐书意图词（推荐/哪些/书单/类似/有没有/想读/读什么）则带推荐书目。**非大模型、无 SSE、无多轮上下文。**
- **持久化**：`busy` 由 true→false 时 `upsertSession`（标题取首条用户消息前 20 字，存 `ail-chat`）。
- ⚠️ 长按输入框可触发语音录制浮层（上滑取消 / 松开发送），但识别能力未接入：松开 toast「语音识别将在接入后端后启用，敬请期待」（info），上滑取消 toast「已取消」（info）。

### 【28】智学消息 · `ChatMessage`（原型 28_chat_message_actions）
- 用户气泡右（celadon-soft）只显纯文本；AI 气泡左（素白卡 + Mascot），`react-markdown + remark-gfm` 渲染（`prose-cn`）。
- **思考态**（`streaming && !content`）：只显「思考中」+ 跳动圆点，**不套整块气泡**。
- **引用卡**（`citations` 非空）：「引用了 N 个章节」+ 逐条 [封面 + 《书名》第 N 章 章节标题 + 摘要]，点击跳 `/library/book/[bookId]/read?ch=[bookId]-c[chapterNo]`。
- **推荐书目**（`recommendations` 非空）：「推荐书目」+ 横滑书封（点击跳 `/library/book/[id]`）。
- **操作栏**（非 streaming 才显）：

| 元素 | 手势 | 结果 |
| --- | --- | --- |
| 👍 赞 | 点击 | 切换 up/取消；置位时 toast「感谢反馈」；回写 feedback |
| 👎 踩 | 点击 | 切换 down；down 时展开反馈浮层 |
| 反馈浮层 | 选标签 | 标题「这条回答哪里不满意？」；**4 标签多选：推荐偏差 / 答疑有误 / 解读没用 / 其它** |
| 反馈浮层「其它」 | 选中 | 展开自定义输入框（autoFocus，placeholder「说说具体问题…」，≤200 字） |
| 提交 | 点击 | 关浮层 + toast「已收到，会继续改进」（**所选标签与自定义文本均仅本地，提交后不保存/不上报**） |
| 复制 | 点击 | 复制 AI 全文，toast「已复制」/「复制失败」 |
| 重新生成 | 点击 | 仅最后一条 AI 且非 busy 时出现；用同问题重跑 |

- **Mascot**：默认真实图 `/mascot.webp`（吉祥物「小涤」），`onError` 回退印章框 + UserRound。

### 【08】对话历史 · `/chat/history`（原型 08_chat_history）
- **形态**：二级页（无底栏）。顶栏[返回 ·「历史对话」· 右「清空」（无搜索词且有会话时显）]。
- **布局**：搜索框（占位「搜索对话或内容」）→ 会话列表（真实 sessions + 未被隐藏的示例会话，按 updatedAt 倒序，预览 28 字 / 空则「（示例对话）」）→ 底部 mountain 纹样。

| 元素 | 手势 | 结果 |
| --- | --- | --- |
| 搜索框 | 输入 | 按标题或任意消息内容过滤（见下「搜索态」） |
| 会话行 | 点击 | 跳 `/chat?s=会话id` 还原该会话 |
| 删除（Trash2，**真实/示例会话都显示**） | 点击 | 弹确认「确认删除这条对话？」→「删除」；真实→`removeSession`（永久删），示例→`hideSample`（**持久隐藏，刷新不再复现**）；toast「已删除」 |
| 清空 | 点击 | 弹确认「确认清空全部对话记录？」→「清空」；`clearSessions`（永久清真实）+ `hideAllSamples`（持久隐藏示例）；toast「已清空」 |

- **搜索态**：每条命中搜索词的消息展开为独立条目（顶部「共 N 处匹配」+ 关键词高亮 + 片段以关键词为中心截取）；仅标题命中的会话单独成一条。点条目 `openHit` 跳 `/chat?s=&q=&mid=`（带消息 id 则精确定位）。
- **空态**：无会话=「还没有对话记录 / 去智学问点什么吧 /（按钮）去智学」；搜索无果=「没有找到相关对话 / 换个关键词试试 /（按钮）清除搜索」。

## 四、模块 2｜泡馆

### 【01】泡馆首页 · `/library`（原型 01_library_home）
- **形态**：泡馆 Tab 根页面（**显示底栏**）。自定义吸顶顶栏：左 `/emblem.webp` 馆徽 +「AI 图书馆」· 右搜索图标（→`/search`）。

| 元素 | 手势 | 结果 |

| 搜索图标 | 点击 | 跳 `/search` |
| Banner 卡（HeroCard，显「{分类} · 新书」+ 书名 + intro + 「立即阅读」） | 点击 | 整卡跳 `/library/book/[id]`（详情） |
