## 一、通用约定（适用于所有页面）

### 1.1 角色与登录态
| 角色 | 能力 |
| --- | --- |
| 游客（未登录） | 可浏览全部模块、看视频/听音频/读全文、用智学问答（历史仅本地、关页即失）、搜索 |
| 登录用户 | 在游客基础上：收藏、划线/笔记、写书评、阅读进度云同步、个人数据、云端对话历史 |

**登录拦截（统一行为）**：游客点击需登录的操作（收藏 / 写书评 / 划线笔记 / 进"我的"个人数据 / 点赞书评）时，**从底部升起登录抽屉**（原型 05），不跳转、不丢失当前页上下文；登录/注册成功后**关闭抽屉并就地完成原操作**（如自动完成收藏）。

### 1.2 全局手势
| 手势 | 行为 |
| --- | --- |
| 点击返回箭头 / 右滑边缘 | 返回上一页（二级页通用） |
| 底部 Tab 点击 | 切换四大模块根页面，保留各 Tab 滚动位置与状态 |
| 列表上拉触底 | 自动加载下一页（无限滚动），底部显示加载圈；到底显示「已经到底了」 |
| 下拉 | 列表页下拉刷新（顶部出现青瓷加载圈） |
| 长按文本（阅读页） | 进入划线选择态（见 13 页） |

### 1.3 底部导航（详见设计规范 7.1）
- 四 Tab：智学 / 泡馆 / 乱翻 / 我的；激活=青瓷绿（图标填充+文字+2px 指示条）。
- **仅 4 个根页面显示**：智学根、泡馆首页、乱翻（进入即隐藏）、我的主页。
- 二级页一律**隐藏**底部栏，顶部用返回箭头。

### 1.4 反馈与状态（统一组件）
| 状态 | 表现 |
| --- | --- |
| Toast | 顶部居中胶囊，2.5s 自动消失（原型 26 顶部示例）。成功=青瓷勾，失败=胭脂叹号 |
| 加载-列表 | 骨架屏 shimmer（原型 25） |
| 加载-按钮 | 按钮内嵌 spinner，禁用重复点击 |
| 加载-视频/音频 | 缓冲圈 |
| 空状态 | 插画 + 文案 + 引导按钮（原型 24 为模板，各列表替换文案） |
| 错误-网络 | 整页错误兜底（原型 26）：插画 +「网络开小差了」+「重试」 |
| 错误-局部 | 局部区块显示「加载失败，点击重试」 |

### 1.6 Mock 接口约定（后端就绪前）
- 所有接口走 `/api/*`（Next.js Route Handler），后端未就绪时返回 `lib/mock/*.ts` 的假数据，**接口签名与真实一致**，后端接入只换实现不改前端。
- Mock 数据集：8–10 本示例书（终身成长/人间词话/被讨厌的勇气/亲密关系/深度工作/自控力/刻意练习/认知觉醒…），每本含元数据 + 3–5 章 + 视频/音频 URL（占位）+ 全文。
- 统一响应：`{ code:0, data, message }`；分页 `{ items, nextCursor, hasMore }`。

## 二、模块 0｜全局页面

### 【05】登录注册抽屉 · `05_login_register.png`
- **形态**：底部升起的 Modal 抽屉（圆角 22px），背景半透明遮罩（点遮罩或下滑关闭）；**不是独立路由页**，可在任意页触发覆盖其上。
- **入口**：① 我的页未登录点任意需登录项；② 任意页触发登录拦截（1.1）；③ 详情页点收藏/写书评（游客）。
- **底部栏**：无（Modal）。
- **布局（上→下）**：关闭把手 → 青瓷印章 Logo → 标题「登录 / 注册」→ 邮箱输入框 → 密码输入框 → 主按钮「登录」→ 文字链「没有账号？立即注册」→ 底部「先逛逛」。
- **交互清单**：

| 元素 | 手势 | 结果 |
| --- | --- | --- |
| 邮箱框 | 输入 | 实时校验邮箱格式；非法时失焦显示胭脂红描边+提示 |
| 密码框 | 输入 | 右侧"眼睛"切换明文；校验≥8位含字母+数字 |
| 登录按钮 | 点击 | 调 `POST /api/auth/login`；loading 态；成功关抽屉+就地回原操作+Toast「欢迎回来」；失败 Toast「邮箱或密码错误」 |
| 立即注册 | 点击 | 抽屉内切换到注册态（加"确认密码"框，主按钮变「注册」）；调 `POST /api/auth/register`；成功=自动登录 |
| 先逛逛 | 点击 | 关抽屉，停留当前页（游客态） |
| 遮罩/下滑 | 点击/下滑 | 关抽屉，放弃操作 |

- **数据**：Supabase Auth（Email/Password）。Mock：任意邮箱+合法密码即登录成功。
- **状态**：登录中=按钮 spinner；错误=输入框胭脂描边+顶部 Toast。
- **动效**：抽屉 spring 升起 260ms；切换登录/注册态高度过渡。
- **功能点**：0.2 登录入口/注册/账号密码登录/游客模式。

### 【06】全局搜索 · `06_search.png`
- **形态**：全屏二级页（**无底部栏**，顶部返回+搜索框+取消）。
- **入口**：泡馆首页顶部搜索图标。
- **布局**：顶部[返回箭头 · 搜索输入框 · 取消] → 「最近搜过」可删除词条 chips → 「热门搜索」chips → 输入后变为结果区：「书籍」分组（书行卡）/「章节」分组/「智学问答历史」分组（登录可见）。
- **交互清单**：

| 元素 | 手势 | 结果 |
| --- | --- | --- |
| 搜索框 | 聚焦 | 自动弹键盘；显示历史/热门 |
| 搜索框 | 输入(防抖300ms) | 调 `GET /api/search?q=`，下方实时出结果分组 |
| 历史 chip | 点击 | 填入并搜索 |
| 历史 chip ×| 点击 | 删除该条（`DELETE /api/search/history/[id]`） |
| 「清空」 | 点击 | 二次确认后清空历史 |
| 热门 chip | 点击 | 填入并搜索 |
| 书籍结果项 | 点击 | 跳 `/library/book/[id]` |
| 章节结果项 | 点击 | 跳该书阅读页并定位该章 |
| 取消 | 点击 | 返回泡馆首页 |

- **数据**：`GET /api/search`（检索书名/作者/标签/章节标题）。历史：登录云存`search_history`，游客 localStorage（最多10条）。
- **状态**：无输入=历史+热门；有输入无结果=「没有找到相关内容」空插画；加载=结果区骨架。
- **功能点**：0.3 全部。

### 【22】阅读设置面板 · `22_reading_settings.png`
- **形态**：阅读页内底部升起的半屏面板（遮罩可关）。
- **入口**：阅读页底部工具栏「字号」或「背景」。
- **布局**：「字号」小/中/大/超大（4 段，当前青瓷高亮）→「背景」白/米黄/护眼绿/深灰（4 色板，当前青瓷环）→「翻页方式」滚动/翻页（切换）→「亮度」滑块。
- **交互清单**：

| 元素 | 手势 | 结果 |
| --- | --- | --- |
| 字号段 | 点击 | **实时**改变正文字号（无需确认）；存 prefs |
| 背景色板 | 点击 | 实时改阅读底色；存 prefs |
| 翻页方式 | 点击 | 切换滚动/左右翻页模式 |
| 亮度滑块 | 拖动 | 调屏幕内容亮度（CSS filter） |
| 遮罩 | 点击 | 关面板，设置已即时生效 |

- **数据**：写入 `profiles.prefs`（登录）或 localStorage（游客）。
- **功能点**：0.4 阅读字号/阅读背景。

### 【25】加载骨架屏（通用模板） · `25_loading_skeleton.png`
- **用途**：首屏/列表数据加载时的占位（shimmer）。此图为泡馆首页骨架。
- **规则**：每个真实区块对应一个灰块占位，结构与真实布局一致；数据到达后交叉淡出 150ms 切换为真实内容。各列表页套用各自结构的骨架。
- **功能点**：0.5 加载态。

### 【26】错误页 + Toast（通用模板） · `26_states.png`
- **整页错误**：网络/500 时整页显示插画 +「网络开小差了」+「请检查网络后重试」+「重试」按钮（点击重新请求）。500 另附「复制错误码」。
- **Toast**：顶部居中胶囊（此图示意「已加入我的收藏」）。统一调用 `toast.success/error(msg)`。
- **功能点**：0.5 全局错误兜底/Toast；3.3 视频失败兜底（视频区局部错误+跳音频/文字按钮）。

### 【27】深色模式（主题示例） · `27_dark_home.png`
- **用途**：展示全局深色模式（以泡馆首页为例），所有页面需支持浅/深/跟随系统。
- **规则**：深色用 `dark-bg #14140F` / `dark-card #1F1E18` / `dark-text #EDE6D6`，青瓷绿+黄铜强调不变；跟随 `prefers-color-scheme`，并可在设置(21)手动切换。
- **功能点**：0.4 浅色/深色/跟随系统。

## 三、模块 1｜智学（ChatBot）

### 【07】智学欢迎首屏 · `07_chat_welcome.png`
- **形态**：智学 Tab 根页面（**显示底部栏**，智学激活）。会话为空时显示此态。
- **入口**：点底部「智学」Tab；或从「我的」→「我的智学问答」（若无会话）。
- **布局（上→下）**：顶栏[标题「智学」· 右上「+」新建] → 居中青瓷 bot 徽标 → 标题「智学」→ 副文案「问我任何关于图书馆的问题」→ 4 个示例问题卡片 → 底部固定输入框 + 青瓷发送键。
- **交互清单**：

| 元素 | 手势 | 结果 |
| --- | --- | --- |
| 示例问题卡 | 点击 | 直接把该问题作为首条消息发送，进入对话态（02） |
| 输入框 | 聚焦 | 弹键盘，多行自适应（≤5行后滚动） |
| 发送键 | 点击/Enter | 发送，进入对话态；空内容时禁用 |
| 「+」新建 | 点击 | 已在空会话则无操作；否则新建空会话 |
| 左缘右滑 / 顶部「历史」入口 | 手势 | 打开对话历史（08） |

- **数据**：示例问题为前端常量（4 条）。
- **状态**：仅在「当前会话无消息」时显示欢迎态；有消息即变 02。
- **功能点**：1.1 欢迎首屏。

### 【02】智学对话进行中 · `02_chat.png`
- **形态**：智学 Tab 根页面（显示底部栏，智学激活）。
- **布局**：顶栏[「智学」·「+」] → 消息流（用户气泡右/胭脂浅色，AI 气泡左/素白卡+青瓷头像）→ AI 答案含 Markdown + 引用卡 + 推荐书目横滑 → 底部输入框 + 发送键。
- **交互清单**：

| 元素 | 手势 | 结果 |
| --- | --- | --- |
| 发送消息 | 点击发送 | 用户气泡上屏；AI 气泡 **SSE 流式**逐字渲染，光标闪烁 |
| 「停止生成」 | 点击（生成中） | 中断流式，保留已生成内容 |
| AI 气泡 | 长按 | 弹菜单：复制全文 / 重新生成（见 28） |
| 引用卡 | 点击 | 跳对应书阅读页并高亮命中段落（`/library/book/[id]/read?ch=&hl=`） |
| 推荐书目卡 | 点击 | 跳该书详情 `/library/book/[id]` |
| 推荐书目区 | 横滑 | 滚动浏览（最多5本） |
| 输入框 | 输入 | ≤500字；超出禁用发送并提示 |
| 「+」新建 | 点击 | 归档当前会话到历史，开新空会话（回 07 态） |

- **数据**：`POST /api/chat`（SSE 流）。请求带最近 20 轮上下文。后端：问题 embedding→火山 Viking 混合检索 TopK=8→拼上下文→LLM 流式→返回正文 + `citations[]`（含 book_id/chapter/snippet）+ `recommendations[]`。Mock：返回固定流式文本 + 2 条引用 + 3 本推荐。
- **状态**：生成中=流式+「停止生成」；限流(10次/分)=Toast「太快啦，请稍候」；游客=可用，但会话不云存（顶部轻提示「登录可保存对话」）。
- **动效**：消息进入淡入上移；自动滚到底。
- **功能点**：1.1 消息流/流式/Markdown；1.3 命中回显/卡片跳转/推荐书籍；1.4 会话窗口/新建。

### 【28】智学消息操作 + 点踩反馈 · `28_chat_message_actions.png`
- **形态**：对话页(02)中单条 AI 答案的操作态/弹层（非独立页）。
- **布局**：AI 气泡下方操作条[👍 赞 · 👎 踩 · 复制 · 「重新生成」] → 点踩后弹出反馈浮层[标题「反馈问题」+ 4 chips「提示词不准/事实错误/格式问题/其他」+「提交」]。
- **交互清单**：

| 元素 | 手势 | 结果 |
| --- | --- | --- |
| 👍 赞 | 点击 | 高亮青瓷，记录 `feedback=up`，Toast「感谢反馈」 |
| 👎 踩 | 点击 | 弹反馈浮层 |
| 反馈 chip | 点击 | 多选高亮 |
