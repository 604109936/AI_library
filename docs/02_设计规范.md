## 二、字体系统（实际：系统字体栈）

`tailwind.config.ts → fontFamily`：
- `font-sans` = `var(--font-sans), -apple-system, PingFang SC, Noto Sans SC, Microsoft YaHei, sans-serif`
- `font-serif` = `var(--font-serif), Noto Serif SC, Songti SC, SimSun, serif`

⚠️ **实情**：`app/layout.tsx` **未接入 `next/font`**，`--font-sans` / `--font-serif` 这两个 CSS 变量从未被定义，因此实际回退到**系统字体**：
- 正文/UI（`font-sans`）：iOS/macOS 用苹方 PingFang，Windows 用微软雅黑（装有 Noto Sans SC 则用之）。
- 标题/书名（`.font-serif`）：系统宋体 Songti SC / SimSun（装有 Noto Serif SC 则用之）。

`body` 默认 `font-sans antialiased`；`.font-serif` 仅用于**页面标题、书名、空状态标题、智学标语**等关键文字（克制使用）。

**字号**：配置**未自定义** `fontSize` 比例，统一使用 Tailwind 默认级别（`text-xs`/`text-sm`/`text-lg` 等）与任意值（如 `text-[11px]`、`text-[15px]`）。阅读正文 4 档字号由 `useReader.fontSize` 控制：**16 / 18 / 20 / 22**（小 / 中 / 大 / 超大，默认 18）。

## 四、布局与响应式（`app/globals.css`）

- **移动端 / WebView 全宽铺满**；仅在 **≥1024px 桌面**把 `.app-shell` / `.app-width` 限宽 **480px**，并加手机壳描边阴影 `0 0 0 1px rgba(42,44,46,.06)`。`maxWidth.app = 480px`。
- 根路由 `/` 是 **3 秒开屏页**（`app/page.tsx` 客户端组件 `SplashPage`），**非服务端 redirect**：展示 `/splash.webp` 背景（缺图回退青瓷渐变）、`/emblem.webp` 馆徽、标题「AI 图书馆」、两行标语「一座懂你的智慧图书馆 / 汇尽古今好书，伴你在阅读中遇见自己」、右上「跳过 {n}s」倒计时按钮、底部加载进度条（与停留时长同步）。开屏期间预取 `['home']` 首页数据做加载缓冲，停留 **3000ms（`SPLASH_MS`）** 后 `router.replace("/library")` 自动进入泡馆首页，点「跳过」立即进入。
- **viewport**（`layout.tsx`）：`themeColor #F4F2ED`、`width=device-width`、`initialScale 1`、`maximumScale 1`、`userScalable false`（**禁止双指缩放**）、`viewportFit cover`；并有内联脚本把移动端布局视口锁定为设备真实宽度，规避「添加到主屏幕」WebView 渲染偏宽。
- 常用工具类：`.no-scrollbar`、`.pb-safe`（`env(safe-area-inset-bottom)`）、`.h-safe-bottom`、`.skeleton`（shimmer 1.4s，含暗色适配）、`.line-clamp-2/3`、`.reader-deco`（阅读器顶部淡墨竹影装饰带）。

## 六、Markdown 排版（`.prose-cn`）

用于**智学 AI 回答**（`react-markdown` + `remark-gfm`）：
- 正文 `15px / leading-7 / ink-700`；`h1–h3` 用 `font-serif`；`ul/ol` 列表；
- `blockquote` = 青瓷左边框 3px + `celadon-soft/40` 底（引用原文样式）；`code` = `line/60` 底。暗色均有适配。

> ⚠️ **书评正文不走 Markdown**：写书评编辑器正文 placeholder 为「写下你的想法…（至少 10 字）」（**不提 Markdown**），编辑器与列表页**均无 Markdown 解析/渲染**，按纯文本展示。

## 九、底部导航（`components/shell/BottomNav.tsx` — 唯一实现）

- **4 Tab（固定顺序）**：`智学`(MessagesSquare→`/chat`) · `泡馆`(BookMarked→`/library`) · `乱翻`(Clapperboard→`/flip`) · `我的`(User→`/me`)。
- `fixed` 底部、`app-width` 限宽、`pb-safe` + `backdrop-blur`；激活态=青瓷绿（图标加粗 + 文字 + 顶部 2px 青瓷指示条 spring）。
- `variant`：`light`（素白 / 暗卡）｜`dark`（乱翻沉浸态，半透明黑玻璃 `bg-black/35`）。指示条 `layoutId` 为 `tab-indicator-${variant}`，**按 light / dark 分两套**（非全局唯一 layoutId，联调时勿误判为单一标识）。
- **仅 4 个根页面挂载**该组件：`/chat`、`/library`、`/flip`、`/me`；**所有二级页不渲染** `<BottomNav>`，从根上杜绝不一致。

## 十、模块视觉特例

- **乱翻**：全屏暗底沉浸（`100dvh` snap 竖滑），BottomNav 用 `dark` variant；顶部黄铜画框线；右侧操作栏（收藏 / 书评）；底部信息渐变浮层；双击胭脂爱心墨痕迸发。
- **文字阅读**：默认 `reader-bg-moon`，可切 白 / 米黄 / 护眼 / 深灰；正文容器 `max-w-[680px]` 居中（桌面端整体仍受 `.app-shell` ≤480 限宽，故实际列宽取二者更小值）；亮度滑块以 CSS `filter brightness` 作用于正文容器。
- **智学**：用户气泡右（`celadon-soft` 底），AI 气泡左（素白卡 + `Mascot` 头像），引用块走 `.prose-cn` 青瓷左边框。
