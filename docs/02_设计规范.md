# AI 图书馆 H5 — 设计规范 v2.0（新中式）

> 设计方向：**新中式 · 现代东方（New Chinese / Neo-Oriental）**
> 保留东方底蕴，更现代、克制、通透、画廊感。参考：观夏 · 楠书房 · 木墨 · 单向空间新版 · MUJI×东方。
> 本文是原型图与前端开发共用的设计 token 依据。第 3 步前端 `tailwind.config.ts` 直接据此配置。
> （v1.0 旧「古书风/烫金/宣纸黄」已废弃。）

## 二、字体系统

| 角色 | 中文字体 | 英文/数字 | 说明 |
| --- | --- | --- | --- |
| 大标题 / 书名 | 思源宋体 Noto Serif SC（克制使用） | Playfair Display | 衬线，仅关键标题 |
| 正文 / UI（主力） | 思源黑体 Noto Sans SC / 苹方 | Inter | 现代无衬线，清晰当代 |

> 相比旧版「楷/宋衬线为主」，新中式**以现代黑体为主**，宋体仅点缀关键标题，层级更当代。
> 字体加载：Next.js `next/font` 本地托管 + 中文子集化。

## 三、间距 / 圆角 / 阴影 / 描边

- **间距**：4px 基线（4/8/12/16/20/24/32/40/48）。页面左右安全边距 16px。**新中式留白更大**，区块间距偏向 24–32。
- **圆角**（新中式偏大圆角更现代）：按钮 14px｜卡片 18px｜大卡片/弹层 22px｜Banner 24px｜头像/FAB 全圆。
- **阴影**（更轻更柔）：
  - sm：`0 1px 3px rgba(42,44,46,0.05)`
  - md：`0 4px 16px rgba(42,44,46,0.06)`
  - lg：`0 10px 36px rgba(42,44,46,0.08)`
- **描边**：默认 `1px solid #E6E3DB`；强调描边 `1px solid rgba(124,152,133,0.45)`（青瓷）。

## 五、图标

- 风格：**线性 outline + 1.5px**，圆角端点，Lucide React。
- 激活态：填充 + 青瓷色。
- 国风点缀：园林窗格、山形线条、几何回纹（线性极简，非水墨）。

## 六、动效（Framer Motion）

| 场景 | 动效 |
| --- | --- |
| 页面切换 | 淡入 + 8px 上移，220ms |
| Tab 切换 | 青瓷指示条 spring（stiffness 300, damping 30） |
| 收藏 | 胭脂红爱心放大回弹 + 粒子 |
| 卡片进入 | 错位淡入（stagger 60ms） |
| 乱翻滑动 | 物理回弹，200ms ease-out |

> 全局曲线 `cubic-bezier(0.4,0,0.2,1)`；遵守 `prefers-reduced-motion`。

## 七、布局与响应式

- 移动端优先；桌面端内容区居中限宽 480px，两侧大留白（画廊感）。
- 断点 `sm 640 / md 768 / lg 1024`。

### 7.1 底部导航规则（全套 + 前端必须一致）

> ⚠️ 一致性由前端**单一 `<BottomNav>` 组件**保证；原型图仅示意，像素差异以本规范为准。

- **标准四 Tab（唯一版本）**：`智学` ｜ `泡馆` ｜ `乱翻` ｜ `我的`。线性图标 + 文字，高度 56px + `env(safe-area-inset-bottom)`。
- **激活态**：图标填充 + 文字 + 2px 指示，颜色 **青瓷绿 `#7C9885`**；未激活为 ink-500 灰。
- **图标语义**：智学=对话气泡/灯；泡馆=书架/卷轴；乱翻=翻页/视频；我的=人形/印章。统一 Lucide 线性风格。
- **何时显示**：仅在 **4 个 Tab 根页面**显示底部栏 ——
  - 智学根（欢迎/对话）、泡馆根（首页）、乱翻根（全屏，进入后自动隐藏）、我的根（个人主页）。
- **何时隐藏**：所有**二级/详情/全屏页**不显示底部栏，顶部改用**返回箭头**——
  - 如：搜索、书籍详情、视频/音频/文字阅读、划线笔记、书评编辑器、对话历史、章节目录、设置、资料编辑、收藏/笔记/书评/历史列表等。
- 原型图中如出现"非四 Tab 的通用导航栏"或"二级页带底部栏"，均为 AI 误画，以本规则为准。

## 八、模块特例

- **乱翻**：全屏暗色沉浸（dark-bg），保留青瓷绿「读这本书」CTA + 胭脂红爱心 + 黄铜书签；底部渐变浮层。
- **文字阅读页**：默认月白底；可切「白 #FFFFFF / 米黄 #F5F0E6 / 护眼绿 #E8F0E4 / 深灰 #1F1E18」；正文最大宽 680px 居中。
- **智学**：AI 气泡用素白卡，引用块用青瓷左边框 3px + 青瓷浅底（celadon-soft）。
