# AI 图书馆 H5 — 功能清单 v4.0（对齐实际代码·2026-06-08）

> 本文按**当前仓库实际实现**重写（阶段1验收密集修复后，2026-06-08）。
> 产物形态：浏览器/微信内置浏览器打开的 H5（移动端优先，桌面 ≥1024px 居中成手机壳）。
>
> **技术栈（实际依赖，见 `package.json`）**
> - 框架：**Next.js 14.2.15（App Router）** + **React 18** + **TypeScript（strict）**
> - 样式：**Tailwind CSS 3.4**（新中式 token，见 `02_设计规范.md`）
> - 动效：**Framer Motion 11**；图标：**lucide-react**
> - 数据请求/缓存：**@tanstack/react-query 5**
> - 状态管理：**zustand 4 + persist**（落 localStorage）
> - Markdown：**react-markdown 9 + remark-gfm 4**（仅智学回答用）
> - 工具：clsx + tailwind-merge（`cn()`）
>
> **架构实情（重要）**
> - **纯前端，无后端、无数据库、无 `/api` 路由、无 Supabase / 火山 Viking / 七牛云。**
> - 所有「接口」是 `lib/api.ts` 里的 **Mock 函数**，直接读取 `lib/mock/data.ts` 的内存假数据（各函数注释里写了**未来**对应的 REST endpoint，仅为后端接入时的契约占位）。
> - 所有用户数据（登录态 / 收藏 / 笔记 / 划线 / 阅读进度 / 历史 / 我的书评 / 对话会话 / 主题 / 搜索历史）**只存浏览器 localStorage**（zustand persist），换设备不同步、清缓存即丢。隐私政策页对此有明确说明：「当前演示版本的数据仅保存在你的本地设备中」。
> - 图片素材统一由 **codex imagegen** 生成置于 `public/`，缺图有 CSS / 占位回退（见 `02` 第十一节）。**不使用网络图床**。
>
> 🎨 备注：本期已交付**前端 + Mock**；真实后端（账号 / 云同步 / RAG / 媒体 CDN）为后续阶段，不在本仓库代码内。

## 一、角色与登录态（实际）

| 角色 | 能力 |
| --- | --- |
| 游客（未登录） | 浏览全部模块、看视频 / 听音频 / 读全文、用智学问答、搜索、查看与本地存的对话历史 |
| 登录用户 | 额外解锁：收藏、划线 / 笔记、写书评、书评点赞、阅读进度与历史、个人页与「我的」各列表 |

**登录方式（`LoginSheet`）**：底部抽屉，**邮箱或账号 + 密码**一种方式；登录/注册合一（注册多一个「确认密码」）。
- 校验：账号/邮箱 `length ≥ 3`，密码 `length ≥ 6`，注册时两次密码一致。
- **体验账号 `123456 / 123456`**（抽屉内一键填入）。Mock 下任意合法输入即登录成功。
- 有「先逛逛」（关抽屉留在当前页）；**无**第三方登录、**无**手机验证码、**无**忘记密码 / 邮件重置。
- `login(account)` 会写入 `user`（合并 `profile`，并按是否含 `@` 决定 account/email），随后 `seed()` 注入演示「我的」数据。
- `logout()` 会清空本地收藏 / 笔记 / 历史 / 我的书评等（退出确认文案：「退出后本地的收藏、笔记将清空」）。

**登录拦截（两种）**：
1. `requireLogin(action)`：游客触发需登录操作时弹 `LoginSheet`，把操作挂为 `pending`，登录成功后自动执行（如自动收藏、自动发布书评）。用于：收藏、书评点赞、划线 / 保存笔记、写书评、乱翻收藏、`/me` 个人项点击。
2. `RequireAuth` 整页守卫：`/me/favorites`、`/me/history`、`/me/notes`、`/me/reviews`、`/me/settings`、`/me/settings/profile` 内容区未登录显示「登录后查看」引导（Header 仍渲染）。

**进度三套口径（核心）**：
1. `progress`（`Record<id,Progress>`）：**仅文字稿写入**（read 页 `setProgress`），存「全书已读章节占比」+ 最后所在章；服务文字稿续读 / 章节态 / 详情在读 / 继续阅读。
2. `mediaProgress`（0-1 续播位置）+ `mediaPlayed`（0-1 真实播放覆盖，只增，判定播完）：音视频，**详情↔乱翻按书共享**；**音视频从不写 progress**。
3. `readChapters`（已读章节 id）+ `readSeconds`（累计阅读/收听秒数，总时长用）。
进度=100 ⟺ 真正读完。`useReadingClock` 仅可见时计时，切后台/卸载 flush（`addReadSeconds`）。

- `useLibrary`(ail-library，**version:2 + migrate**)：收藏 / 笔记 / 进度（progress）/ 历史 / 点赞（书评 likedReviews + 书籍 likedBooks）/ 我的书评 / **mediaProgress / mediaPlayed / readChapters / readSeconds**。`real(id)=id.split("__")[0]` 用于几乎所有按书 action；`pushHistory` 按「书+大类(av/text)」去重（音视频合一条、与文字分开），最多 50 条；`migrate(v<2)` 清 progress/mediaProgress/mediaPlayed/readChapters/readSeconds/history，保留收藏/笔记/书评/点赞。
- `useReader`(ail-reader)：fontSize(默18) / bg(默moon) / brightness(默1) / defaultMode(默text)。**无 `pageMode` 字段。**
- `useChat`(ail-chat)：sessions + **hiddenSamples**（持久化被删/清空的示例会话 id）；`upsertSession` / `removeSession` / `clearSessions` / `hideSample` / `hideAllSamples`。
- `requireLogin(action)`：未登录弹 LoginSheet 并挂 pending。
