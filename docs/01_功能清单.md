# AI 图书馆 H5 — 功能清单 v1.0

> 编制日期：2026-05-26
> 目标产物：浏览器打开使用的 H5 APP（移动端优先 + 桌面端响应式）
> 技术栈基线：
> - **前端**：React 18 + Next.js 14 (App Router) + TypeScript + Tailwind CSS + shadcn/ui + Framer Motion + React Query + Zustand
> - **后端**：Next.js API Routes（Node.js 运行时，与前端一体部署）
> - **数据库**：Supabase (PostgreSQL + Auth + Storage + RLS)
> - **向量库**：火山 Viking（章节级 RAG 检索）
> - **媒体存储**：七牛云 CDN（视频/音频文件）
> - **AI**：LLM 流式接口（具体模型待选，火山豆包/OpenAI/Claude/DeepSeek 等均兼容）
> - **部署**：GitHub + Vercel

> 📌 说明：Next.js 是基于 React 构建的全栈框架。所有组件用 React + JSX 写，Next.js 在此之上提供路由、SSR、API、构建、部署等能力。
>
> 🎨 图片素材约定（重要）：APP 内所有需要的图片素材（图标、插画、空状态图、占位封面、品牌元素、Banner 等）统一由 **parallel-imagegen Skill** 批量生成，不使用网络图床或第三方版权图。书籍真实多媒体（视频/音频）由您自己的离线流程上传至七牛云。

## 一、整体架构与角色

| 角色 | 说明 |
| --- | --- |
| 游客（未登录） | 可浏览全部模块、播放视频/音频、阅读全文，但**不能**收藏、做笔记、写书评、查看个人数据 |
| 注册用户 | 拥有完整功能；个人数据云端同步、多设备一致 |
| 内容管理员 | 您自己（通过外部 Skill 工作流灌库），APP 内**不提供**后台管理界面 |

**数据职责划分**：

| 数据类型 | 存储位置 | 说明 |
| --- | --- | --- |
| 用户账号、Session | Supabase Auth | v1.0 仅 Email + 密码；手机验证码 / 第三方 OAuth 留待 v1.1 |
| 书籍元数据（书名/作者/封面/标签/视频URL/音频URL等） | Supabase `books` 表 | 用于书库列表、详情页、筛选 |
| 章节元数据（chapter_id/book_id/chapter_no/chapter_title） | Supabase `chapters` 表 | 用于章节目录、阅读跳转 |
| 章节正文 + 向量 + 语义检索字段 | 火山 Viking | 唯一权威来源，按需读取 |
| 用户行为（收藏/笔记/划线/书评/阅读进度/智学历史） | Supabase 各业务表 | 行级安全策略（RLS）保护 |
| 视频/音频文件 | 七牛云 CDN | Supabase 只存 URL |

## 五、用户旅程示例（验收时帮助你判断是否完整）

1. **首次进入**：游客打开 H5 → 看到泡馆首页 Banner → 点心理学分类 → 看到《终身成长》→ 进详情页 → 切到文字阅读 → 看了 2 章决定收藏 → 触发登录引导 → 邮箱注册 → 自动回到详情页完成收藏。
2. **深度阅读**：登录用户进《终身成长》→ 文字模式读到第 3 章 → 长按一段话 → 高亮 + 写笔记 → 退出 → 下次进入自动回到第 3 章相同位置。
3. **AI 辅助**：用户在智学问「《终身成长》的核心观点是什么」→ AI 流式输出 + 末尾引用第 1 章原文卡片 → 点卡片直接跳到第 1 章高亮位置。
4. **乱翻发现**：用户切到乱翻 → 上下滑刷了 5 个视频 → 看到一个商业类视频感兴趣 → 双击点赞 → 点「读这本书 →」跳到文字阅读。
5. **个人沉淀**：用户进我的 → 笔记 → 按书分组看到 3 本书 12 条笔记 → 导出 Markdown 到本地。
