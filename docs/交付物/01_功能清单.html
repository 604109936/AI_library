AI 图书馆 · 产品功能清单

一座「会回答问题」的图书馆

「AI 图书馆」是一款面向中文读书人的移动端(H5) App，已上线 goodcontent.cn。它把四件事装进一个手机壳里：向 AI 读书伙伴「小涤」要书/答疑/解读原文(智学)、在分类书库里读文字稿·听音频·看竖屏解读视频(泡馆)、像刷抖音一样竖滑发现新书(乱翻)、在个人中心沉淀收藏/笔记/书评/进度/时长(我的)。核心价值是"被懂"——AI 与每日推荐都结合你读过/在读/收藏/笔记的真实数据做个性化，所有阅读痕迹经 Supabase 跨设备云同步、登出即清不串号。游客可零门槛浏览全部书库与刷视频，登录后解锁个性化与数据沉淀，适合想被引导着读书、碎片化发现好书的普通读者。

架构与数据流

数据分两条链路。【目录类只读数据】(书库/分类/章节/搜索/乱翻池)：前端用 Supabase anon key 直连 Postgres 公开读(lib/api.ts)，TanStack Query 缓存渲染，游客即可浏览。【用户私有数据】(收藏/笔记/高亮/进度/书评/历史/时长/对话)：登录后 loadUserData 一次性把本人多表灌进 Zustand 内存(useLibrary 不本地持久化、Supabase 为唯一事实源)，各操作走『本地乐观更新 + 异步写穿透 Supabase、失败 Toast』；三道护栏贯穿全篇——canSync(uid+hydrated 双门禁防空基线洗云端)、世代校验(uid 比对防换号串档)、节流(媒体 5s/计时 30s)。安全主防线是数据库 RLS：目录表公开读、用户表 per-user 策略，service_role 仅服务端云函数用。【AI 链路】智学问答前端带 Bearer access_token 调 /api/chat，服务端组装 system(全馆书单+读者画像+长期记忆+压缩摘要)→MiniMax M3 工具循环(荐书/目录/章节/引用/联网)→NDJSON 流式逐块返回，答完经 waitUntil 后台跑上下文压缩(chat_sessions)与长期记忆(user_memory)。【个性化推荐】Vercel Cron 每日 04:00 调 /api/cron/flip-feed，用 MiniMax 按画像为每人排出乱翻书单写 flip_feed。【触发器/RPC/pg_cron】数据库侧自动维护收藏数/评分/在读人数与多设备进度合并。仅 3 个 API 路由(对话/注销/Cron)，其余 CRUD 全走 supabase-js 直连。
