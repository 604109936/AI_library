# 优化迭代记录

> 格式：**现状问题 → 解决方案 → 效果**。持续追加，最新在下。

## 一、智学对话 Agent

### 1. 问天气却弹荐书卡(答非所问)
- 问题：荐书后接着问天气，回答里串出上一轮的荐书卡；有时只出卡没正文。
- 方案：删掉全部反应式兜底补救轮(净删166行)，改纯「提示词+工具描述+主动编排」；实时问句回合代码层拦截跑题荐书卡(suppressRecs)。
- 效果：43项回归全绿；问天气不再弹书卡、正文正常。

### 2. 对话首字慢且不稳(2~15s)
- 问题：Claude 经 vtok.ai 代理首字延迟 2~15s 抖动、出字仅42字/s。
- 方案：主对话模型切火山豆包 Doubao-Seed-2.1-pro(实测工具调用20/20、首字0.4s)；CHAT_MODEL env 一键回退；压缩/记忆/乱翻排序后台任务同步切豆包统一模型栈。
- 效果：首字 15s→0.4s；后台任务更快更省。

### 3. 联网搜索质量差 + 原始JSON泄漏进正文
- 问题：MiniMax 搜索结果差；自定义工具名 web_search 与 Claude 原生工具撞名导致原始 JSON 直出。
- 方案：搜索后端切火山方舟 Responses API(annotations 溯源)；工具改名 web_lookup；实时问句走 Option B 流式直答(直吐火山回答+源卡，跳过二次作答)。
- 效果：权威中文源、带精确时间；泄漏0/5；实时问答提速约一倍(~6-7s 流式)。

### 4. 荐一本给三本 / 概览复读目录 / 结尾追问与卡片抢戏
- 问题：说"荐一本"给3本卡；"讲什么的"把目录逐模块复述(1500+字)；结尾问"想先聊哪块"却已摆出4张章节卡。
- 方案：提示词"尊重数量/消化转述/相邻不重复"；章节卡收敛(概览1~2张)；新工具 suggest_replies 追问气泡代替正文反问；气泡禁出"拉原文"类(与章节卡入口去重)。
- 效果：荐一本卡只1本；概览瘦身近半；三入口变两入口各司其职。

### 5. 书单方案A(迎接100本)
- 问题：全量概要书单 ×100本≈3.5万token/请求，拖首字、烧钱、稀释注意力。
- 方案：书单每本一句话简介(books.short_intro，gen-short-intros.mjs 批量生成，import-books 第7步自动补)；新工具 get_book_briefs 荐书前批量取完整概要防编造。
- 效果：书单体积-70%；39项回归全绿、荐书理由质量不降。

### 6. 生成中看来源网页回来"断线了"
- 问题：微信冻结页面杀流式连接，生成死掉只剩半截。
- 方案：断线治本——genId 恢复凭证 + 服务端 waitUntil 续跑 + chat_gens 快照(恒2.5s节奏,15min TTL) + 回前台轮询回填；「继续生成」按钮从断点续写兜底；快捷追问/继续生成等入口配套。
- 效果：生产实测断连后续跑到 done、回来无感恢复。

### 7. 流式中途卡住像断线
- 问题：模型出字间歇时正文冻住无信号。
- 方案：停顿>1.8s 在末字后内联浮现三个呼吸点，恢复出字即消失。
- 效果：流畅时零打扰、卡住时即时安抚(不换行紧跟末字)。

### 8. 裸 ** 星号渲染碎裂
- 问题：加粗紧贴中文标点时 CommonMark 判定加粗不成立，满屏星号。
- 方案：渲染层 fixCjkBold——仅在必失败位置插入极细空格 U+2009；提示词同步规范。
- 效果：6例单测全过，正常加粗零影响。

### 9. 空回复"这次没说出话来"
- 问题：模型偶发零文字(尤其强制联网后一轮)。
- 方案：保留唯一一层 robustness——空回复静默补一轮(不靠正则猜错误)。
- 效果：生产连测3/3有正文。

### 10. 新会话冷启动没引导
- 问题：游客/零记录用户只见标题。
- 方案：破冰开场白气泡 + 个性化chips混入1条"情绪/求助型"(50轮单测恒4条恒前3位)。
- 效果：最低门槛入口直达对症荐书。

## 二、语音输入

### 11. 首次长按不识别 / 丢前几个字 / 偶尔整句失败
- 问题：拾音晚于开口(getUserMedia+建图~600-900ms)；中继冷启动；WS中途断无补救；松手等待窗误判"没听清"。
- 方案：按下即预拾音+WS预连(preCapture，点按则关麦仅橙点闪现)；AudioContext 常热复用；整句PCM留底+断线重拨重发；等待窗自适应(有实时字600ms秒发/零字从EOS送达起算6s)；中继75s保温心跳；完整性存疑回填输入框不擅自发送。
- 效果：丢字归零、松手到发送快0.5-1s、冷链路不再误报"没听清"。

### 12. 长按弹语音面板延迟
- 问题：面板等 getUserMedia 完成才弹。
- 方案：长按判定(350→280ms)即乐观弹面板，启动失败再收起。
- 效果：按下即弹零等待感。

## 三、乱翻(视频流)

### 13. 进入有时自动暂停/自动静音
- 问题：带声自动播放被浏览器政策拦；iOS带声许可按video元素记(复用池3元素只解锁1个)；政策暂停后裸play无兜底卡死；"轻点开声"又被单击判定暂停。
- 方案：手势内解锁整个视频池(unlockPool起播即停)；kick提升document级+data-nokick排除控件；onPause补播走playActive(keepMuted)自愈；静音态首击=开声不暂停(按手势快照)。
- 效果：经对抗评审修4必修点后上线；滑动不再中途静音、不再冻住无按钮。

## 四、性能与工程

### 14. 首字4.4s(跨太平洋) → hkg1翻车 → 回退
- 问题：Vercel美区↔火山北京流式往返慢；hkg1香港连不通火山大陆端点致全站502。
- 方案：紧急回退默认区域；教训：切区先验证目标端点可达性。
- 效果：站点恢复；提速另寻不破连接的路径。

### 15. 进泡馆/智学/乱翻卡顿(现载)
- 问题：进页面才开始下载代码+数据+图片。
- 方案：BottomNav 挂一次性空闲预载(requestIdleCallback)：预取 getHome(两页共用)+前8张封面预热+四Tab JS prefetch+乱翻查询暖链路；不做强制开屏等待页。
- 效果：切页不再等接口和图片，弱网失败无感回退现载。

### 16. 联网来源卡体验
- 问题：多次搜索出多张卡、不知道哪批资料对应哪个搜索词；等待死水波纹。
- 方案：豆包式聚合一张卡、按搜索词分组；水波纹显示「正在搜「词」」；章节卡头改「引用 N 章 · 点开读原文」。
- 效果：溯源清晰、等待可感知。
