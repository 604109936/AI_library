## P1 级（6 项全修）

1. **乱翻快滑切条复活旧槽**（app/flip/page.tsx playActive）
   现象：弱网快滑时旧视频后台播放/声音图标失真/静音提示被烧/错误层盖错条。根因：play() Promise 落定回调无「槽位仍活跃」校验（pause 会让 pending play 以 AbortError 拒绝）。修复：stillActive() 守卫贯穿 then/catch/重试三处。
2. **流式中间态消息被永久持久化**（app/chat/page.tsx persist）
   现象：流式中给早先消息点赞→streaming:true 落本地→历史重开永久"思考中"。根因：persist 无归一化。修复：persist 过滤 streaming 消息+剥 toolNote（与云端 cleanMsgs 口径对齐）；历史还原时归一化自愈已污染数据。
3. **压缩裁剪索引黑洞**（lib/server/compress.ts）
   现象：会话含 error 占位/纯卡片消息时，摘要边界附近真实消息"既不在摘要也不在请求"。根因：compressed_until 按 DB 原始下标计数，前端请求数组口径不同。修复：新增 requestView() 统一三套口径（剔 error→剥标记→滤空），until 改按请求口径计数。
4. **阅读器续读抢跑写脏进度**（read/page.tsx）
   现象：续读未决议时以第 1 章抢跑上报，覆写 ail-chpos 精确位置、向云端写错章。修复：resolved 状态门禁（决议完成才放行进度 effect，finally 保证所有路径置位）；pendingPct 待恢复时跳过 chpos 写入。
5. **高亮切章 React 协调冲突**（read/page.tsx 正文容器）
   现象：有划线的章与结构不同的章之间切换，可能 NotFoundError 白屏或残留上一章文字碎片。根因：wrapRange 对 React 托管节点 splitText/包 mark，切章时 React 原地 diff 被改动过的 DOM。修复：正文容器 key={cur.id} 按章整棵重挂载。
6. **loadUserData 静默失败打开写穿透**（lib/supabase/userdata.ts + store.ts load）
   现象：任一查询失败被当"无数据"，空基线+hydrated=true 合法洗掉云端进度。修复：10 路查询逐路检查 error 失败必 throw；load() 重试一次仍失败则保持 hydrated=false + toast 提示（写穿透关死）。
