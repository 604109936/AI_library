# AI 图书馆 H5 — 后端开始前·功能清单（完备版）

> 用途：进入**后端开发阶段**前的总参考。**以实际代码为主**（前端已实现的真实行为），**以 `docs/AI图书馆功能详细说明补充.md` 为辅**（后端业务、智学 Agent 等）。二者冲突一律**以代码为准**（代码是与用户商量定过的）。
> 日期：2026-06-08。配套：`docs/01_功能清单.md`~`05_交互说明.md`（前端现状）、`docs/后端_Supabase建库SQL.md`（建库 SQL）、`docs/AI图书馆功能详细说明补充.md`（业务原始说明）。

## 技术架构
- **前端**：Next.js 14（App Router）+ React 18 + TS + Tailwind 3.4 + zustand + react-query；H5 移动端优先。
- **后端/数据**：**Supabase 直连**（Postgres + Auth 邮箱密码 + RLS 行级安全 + Storage）；前端用 `supabase-js` 直接读写，`lib/api.ts` 的 Mock 逐个替换为 supabase 查询（签名不变）。
- **智学 AI**：**minimax TokenPlan** 套餐 API（Agent「小涤」+ 异步压缩 + 联网搜索调研）；一个轻量云函数保护密钥。
- **媒体素材**：每本书的**封面 / 视频 / 音频在阿里云 OSS**（表里只存 URL）；氛围图/海报为前端按分类静态图；Supabase Storage **只建 `avatars` 桶**（用户上传头像）。
- **部署**：Vercel（前端）+ Supabase + 阿里云 OSS。

### 0.1 角色与登录态

当前为纯前端 Mock 登录：任意合法输入即登录成功，登录态存 `localStorage`（`ail-auth`），无 JWT、无续期、换设备不同步。后端阶段改为 **Supabase Auth（邮箱 + 密码）**，新用户由 `on_auth_user_created` 触发器自动建 `profiles` 档案。游客可浏览/看视频/听音频/读全文/问答/搜索；登录用户额外解锁收藏、划线/笔记、写书评、阅读进度/历史、个人页各列表。

## 模块6｜数据模型 & 数据库表概览

> 口径说明：本节以「实际代码（`lib/types.ts` / `lib/store.ts` / `lib/api.ts` / `lib/mock/data.ts`）」为主、以「`docs/后端_Supabase建库SQL.md` 与 `docs/AI图书馆功能详细说明补充.md`」为辅；二者冲突一律以代码为准。
> 当前仓库为「纯前端 + Mock」，所有用户数据存浏览器 localStorage（zustand persist：`ail-auth` / `ail-ui` / `ail-library` / `ail-reader` / `ail-chat`）。下表的「后端要点」即阶段3落库后各表/字段的对应关系。
> 全库共 **14 张表**：目录类 3（categories / books / chapters）+ 账号 1（profiles）+ 用户数据 10（favorites / notes / reviews / review_likes / reading_history / text_progress / media_progress / chat_sessions / flip_feed / search_logs）。
> 命名约定：表/列一律 snake_case；`id` 沿用前端文本 id（如 `mindset` / `mindset-c1` / `psy`）便于平滑迁移；用户数据表的 `book_id` **不外键到 books**（解耦/便于迁移，删书可能留孤儿行，关联一律 left join + 兜底）。
> 存储：**每本书的「封面 / 视频 / 音频」在阿里云 OSS**（`books.cover_url / video_url / audio_url` 填 OSS 公开 URL）；氛围图(hero)/海报(poster) 是「按 categoryId 取的前端静态装饰图」（`public/`，不入库）；作者头像 APP 未使用、不入库。**Supabase 只建 `avatars` 一个桶**（存用户「编辑资料」上传的头像 → `profiles.avatar_url`）。

| likes（点赞=收藏，无独立列） | `Book.likes` 与 store `likedBooks`/`toggleBookLike` 是历史冗余、当前未使用 | books 表**不设独立 likes 列**；语义上「点赞数=收藏数=fav_count」。阶段3 接前端时清除前端 likedBooks 冗余 | 💾仅存数据不展示 |
| readers（在读+读完人数） | 不展示（详情/列表均无在读人数） | `books.readers = 该书在 reading_history / text_progress / media_progress 出现的 distinct user 数` → 定时任务/视图统计回写 | 💾仅存数据不展示 |
| read_count（阅读次数，不去重） | 不展示；同一人多次阅读累加（与去重的 reading_history 无关） | `books.read_count = read_count + 1` 经 service_role RPC 自增（**不去重**）；需后端先定义「何为一次阅读」（如进入阅读/播放达一定比例） | 🔧后端待开发 |
| review_likes（书评点赞计数） | 本版不展示他人书评、点赞不前端生效 | `reviews.likes` 由 `review_likes` 聚合维护（触发器/后台刷新） | 💾仅存数据不展示 |

## 模块9｜已确认的设计口径 / 取舍

> 以下为与用户商量定过、并以代码为准的口径，建表/接口/Agent 实现一律遵从。

| 口径项 | 结论（实际代码为准） | 影响 |
| --- | --- | --- |
| 点赞 = 收藏 | 无独立点赞概念，乱翻双击/侧栏爱心均走 `toggleFav`(写 favorites)；收藏人数=fav_count=点赞人数 | books **不设独立 likes 列**；`Book.likes`/store `likedBooks` 阶段3 清除 |
| 读者评价（他人书评） | 本版**只存数据、不前端展示**：`/library/book/[id]/reviews` 路由已删；详情仅显「我的评价」一条 | reviews/review_likes RLS 仅本人可读、不开公开读；getBookReviews/toggleLike 保留备后端 |
| 评分 / 在读人数 / 收藏数 / 书评数 / 阅读次数 | 存 DB（rating/readers/fav_count/review_count/read_count）但**前端全程不展示**（列表/详情展示的星级是 review.rating，「约 X 字」是 words） | 计数字段需后端维护（模块7），否则恒为 0 |
| 进行中 / 已读按音视频·文字分开计 | `reading_history` 按「书+大类(av/text)」去重；分类列表/我的历史均**音视频 / 文字稿两药丸筛选、默认音视频** | mode_category in ('av','text') |
| 已移除：书架 / 分享 | 详情操作栏**仅「收藏」**；无书架、无分享、无对话分享 | 不建相关表/字段 |
| 主题仅浅 / 深 | `Theme = "light"|"dark"`，无「跟随系统」、无 prefers-color-scheme | 设置「主题外观」仅两项 |
| 阅读器底部 3 钮 | **目录(List) / 笔记(StickyNote) / 设置(Settings2)**；字号/背景/亮度合并进「设置」面板 | 无独立字号/背景/亮度按钮、无翻页方式 |
