## 覆盖度小结

- **原型 29 张全部有对应实现**（部分被合并或改为组件，见 `03_原型图清单.md` 差异汇总）。
- **核心主流程（浏览 / 阅读 / 划线笔记 / 书评 / 收藏 / 智学问答 / 乱翻 / 我的）均已实现**，数据为前端 Mock + localStorage。
- **🔶 简化项**集中在：登录（纯前端）、流式（假流式）、媒体（合并媒体台、自制全屏）、首页/分类列表口径（Banner 取每类最新、热门按出版时间过滤已读完、真实分页 PAGE=6 不复制）、历史/书评/乱翻操作裁剪。
- **❌ 未实现项**集中在：真实后端与算法（RAG / 推荐 / 云同步）、富功能（TTS / 翻页 / 收藏分组 / 笔记导出 / 书评 Markdown 与互动 / 分享 / PWA 离线）。完整清单见 `01_功能清单.md` 第五节。
- **较 v3.0 的口径修正**：搜索仅书籍一组（最近搜过 5 条 / 热门 12 词）；主题仅浅/深无跟随系统；热门好书无「换一批」、分类页为阅读类型下拉 + 真实分页；`/me` 数据卡实时计算（总时长/已读/进行中/收藏）、菜单四项（书评/笔记/设置/关于）；收藏排序 2 项；书评支持编辑（✅）；阅读历史改音视频/文字稿筛选且无清空；阅读偏好删默认模式；主题删跟随系统；删除「通知设置」行；隐私仅注销；头像支持上传 + 预设。
