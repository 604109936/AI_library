## 开屏页 splash（`/`，`app/page.tsx`）

> 旧文档把根路由 `/` 当作「重定向到 `/library`」是错的：实际 `/` 是一个独立的客户端开屏页（`SplashPage`），停留约 3 秒后自动进入泡馆首页。

- 背景：codex 生成的开屏底图 `/splash.webp`；**缺图回退青瓷渐变**（celadon-soft → moon → snow，深色态对应回退）。
- 馆徽 `/emblem.webp`（圆角方形）+ 标题「AI 图书馆」+ 标语两行：
  - 「一座懂你的智慧图书馆」
  - 「汇尽古今好书，伴你在阅读中遇见自己」
- 右上「跳过 {n}s」按钮：`n` 为倒计时秒数（从 3 开始），点击立即 `router.replace("/library")`。
- 底部加载进度条：与停留时长同步（线性动画，宽度 0% → 100%）。
- 进入即预取首页数据（`prefetchQuery(['home'])`）做加载缓冲；停留 `SPLASH_MS = 3000ms` 后自动 `router.replace("/library")`。

## 实现差异汇总（原型 → 代码）

1. **视频 / 音频不再是独立页**：原型 10/11 在实现中并入书籍详情页顶部的「媒体台」`BookMediaHero`，按该书能力渲染 `VideoStage` 或 `AudioStage`，二者皆有时用「视频/音频」分段切换。
2. **书架 / 分享 全 APP 不做**：详情页与乱翻操作栏均无；原型若有相关元素以代码为准（不实现）。
3. **读者评价（他人书评）本版只存数据、不前端展示**：原 `/library/book/[id]/reviews` 路由**已删除**；详情页只展示「我的评价」一条 + 写/更新书评按钮；写书评入口在详情页与乱翻（→ `/review/new`）。数据层 `reviewsByBook` / `getBookReviews` / 书评点赞保留备后端接入。
4. **对话历史无独立会话路由**：点历史项跳 `/chat?s=会话id`，由 `/chat` 用查询参数还原会话，无 `/chat/[sessionId]`。
5. **搜索结果只有「书籍」一组**，无「章节」组、无「智学问答历史」分组。
6. **阅读设置无「翻页方式」**：仅字号 / 背景 / 亮度；翻页方式始终为竖向滚动且未实现，**store 中亦无相关字段**（旧文档「`useReader.pageMode` 为预留字段」已过时，该字段已不存在）。
7. **TTS 朗读 / 收藏分组 / 阅读日历 / 投屏 / 书评回复·举报**：原计划项**均未实现**；**语音输入**仅有占位浮层 UI（智学页长按输入框弹录音层、上滑取消/松开提示，识别能力待接入后端 ASR），非完整功能。
8. **评分(rating) / 在读人数(readers) 字段保留但 UI 一律不展示**（有意设计，非缺失）。
9. **根路由 `/` 是独立开屏页**（splash，非重定向），见上方「开屏页 splash」词条。
10. 原型为 AI 生成的视觉参考，像素文案以代码与 `05_交互说明.md` 为准。
